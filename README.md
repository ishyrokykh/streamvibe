## 💡 Why Minista?

I wanted to try something different from the usual React/Next.js stack for a landing page project. Minista caught my attention because:

- ⚡ **Fast development** - Vite-powered, instant HMR
- 📦 **Clean output** - Generates pure HTML/CSS/JS without framework overhead
- 🎯 **TypeScript support** - Write .tsx components but get static HTML
- 🤔 **Curiosity** - Wanted to see how it handles interactive components like sliders, tabs, and accordions

**The goal:** Build a modern, Netflix-inspired landing page with interactive components (Swiper sliders, tabs, accordions) using a minimal SSG to see if it's a good fit for content-focused sites with some interactivity.

**What I learned:** Minista works great for static pages with progressive enhancement. For heavy client-side interactions, a full framework might be better, but for landing pages and marketing sites, it's surprisingly capable.
